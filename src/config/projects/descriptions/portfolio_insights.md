#### Branding First
This project aims to *showcase* my skills not only as a **Web Developer**, but also my understanding of **UX/UI**. The main difficulties were to create a *cohesive* brand for myself so it gets recognized easily. As such my aim was to set up a presence for myself that *stands out*. After extensive research I set up the entire **graphical, artistical and interactive direction** of the website.

The Frontend runs in **React.js** using **Framer Motion** for many animation elements and is designed to be heavily modular, allowing for *easy configuration* without a backend necessary. The projects each run on their own *theme*, thus giving the showcase a feel of a branded **presentation**.

Throughout the project I learned much about **animations**, and how to create a setup that allows for *easy* future adjustments and additions.
